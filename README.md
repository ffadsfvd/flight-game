Solvara Skies is an island flight career over the Solvara Archipelago, an invented chain of sun-soaked islands with a volcano, a sea arch, a lighthouse, towns and four airfields (a lit main airport, a grass strip in the hills, a short island field and a seaplane lagoon). You fly three aircraft built in code, a trainer, an amphibian on floats and an aerobatic jet, each with its own flight model (lift from airspeed and angle of attack, drag, thrust, stalls, flaps, gear, brakes, fuel burn, engine heat and damage). Fifteen missions in three chapters cover a first solo, canyon ring time trials, short-field and water landings, cargo runs, a rescue drop, firefighting, aerial photography, a dead-stick glide, a storm approach, aerobatics, formation flying and an air race, with graded landings, pay, ranks, upgrades and a logbook. Play it in desktop Chrome with keyboard and mouse; everything, including the sound and music, is generated in code with no network requests.

## Run it

```sh
node serve.ts (then open http://localhost:8080)
```
